ℹ️ How to get a Claude API Key
  1. Go to Anthropic Console
  2. Sign in or create an account
  3. Go to API Keys section
  4. Click "Create Key"
  5. Copy the key (starts with sk-ant-) and paste it above
ℹ️ How to get a DeepSeek API Key
  1. Go to DeepSeek Platform
  2. Sign in or create an account
  3. Go to "API Keys" in the left menu
  4. Click "Create new secret key"
  5. Copy the key (starts with sk-) and paste it above

💰 Pricing: ~$0.14/million input tokens, ~$2.19/million output tokens (much cheaper than Claude!)
